# Regras deste repositorio publico

- Nunca enviar configuracoes locais, credenciais, nomes/e-mails de operadores, respostas personalizadas, numeros de chamados reais, CPF, UC, matriculas, diarios, historicos ou backups ao GitHub.
- Somente exemplos sem dados pessoais e testes explicitamente ficticios podem ser publicados. Revise todos os arquivos preparados antes de cada commit.
- Os scripts foram copiados do projeto existente. Preserve previa, confirmacao, verificacao de versao, diario, segunda tentativa apenas de leitura e ausencia de reenvio automatico de escritas incertas.
- O painel fica em https://historico-venda-ativa.vercel.app. Use somente a importacao autenticada `/api/historico/importar`; nunca substituir o historico inteiro de colegas.
- Nao executar resolucoes reais durante testes. Testar com mocks, arquivos temporarios e rede externa bloqueada.
- Documentar qualquer adaptacao em ORIGEM.md. Nao modificar o projeto original ao trabalhar nesta copia.
- Apos cada alteracao solicitada, validada e revisada quanto a privacidade, criar commit e enviar para origin/main. Nunca usar force push. Se nao conseguir enviar, informar o impedimento.
